# Power BI Learning Studio

An interactive three-day Power BI learning management system for CA students in Dubai. The app covers data preparation, modelling, DAX, visual design, audit analytics, governance and an end-to-end capstone.

Developed by CA Pradeep Gujaran.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The app includes downloadable lab packs and Power BI reference files in `assets/downloads`.
